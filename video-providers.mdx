# Video & TTS Providers

YouTube Automation Agent features modular multi-provider routing for both visual media generation and audio narration.

## Supported Video Generation Engines

- **Seedance**
- **MiniMax H3**
- **Google Gemini Omni Flash**
- **Kling AI**
- **Wan Video Engine**
- **FFmpeg Canvas Fallback**: Local animation fallback when external API quotas are exhausted.

## Supported TTS Narration Engines

- **ElevenLabs v3**: Ultra-realistic voice generation with custom model selection.
- **OpenAI TTS**: High quality `tts-1` and `tts-1-hd` voices (`alloy`, `echo`, `fable`, `onyx`, `nova`, `shimmer`).
- **Google Gemini TTS**: Direct audio generation via Gemini API.
- **Microsoft Cognitive Services**: Azure Neural TTS integration.
