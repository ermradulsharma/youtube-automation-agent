# Changelog

All notable changes to **YouTube Automation Agent** are documented below.

## [1.0.0] - Initial Release

- **Multi-Agent Core**: 7 specialized agents for YouTube channel automation.
- **AI Video Providers**: Seedance, MiniMax H3, Gemini, Kling, Wan, and FFmpeg canvas fallback.
- **Voice TTS Engines**: ElevenLabs v3, OpenAI TTS, Google Gemini TTS, Azure Speech SDK.
- **Shorts Repurposing**: 16:9 to 9:16 vertical video conversion with subtitle burning.
- **Web Dashboard**: Single-page UI for pipeline management and quality approval gates.
