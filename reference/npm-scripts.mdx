# NPM Scripts Reference

All available scripts defined in [`package.json`](file:///d:/project/youtube-automation-agent/package.json):

| Command | Description |
| :--- | :--- |
| `npm start` | Starts the main orchestrator server and web dashboard (`localhost:3456`). |
| `npm run setup` | Launches console credential setup wizard (`setup.js`). |
| `npm run walkthrough` | Step-by-step interactive onboarding guide (`walkthrough.js`). |
| `npm test` | Executes test suite (`test.js`). |
| `npm run lint` | Runs ESLint verification (`eslint .`). |
| `npm run scheduler` | Starts daily automation cron jobs. |
| `npm run agent:strategy` | Runs Content Strategy Agent standalone. |
| `npm run agent:script` | Runs Script Writer Agent standalone. |
| `npm run agent:thumbnail` | Runs Thumbnail Designer Agent standalone. |
| `npm run agent:seo` | Runs SEO Optimizer Agent standalone. |
| `npm run agent:production` | Runs Production Management Agent standalone. |
| `npm run agent:publishing` | Runs Publishing Scheduling Agent standalone. |
| `npm run agent:analytics` | Runs Analytics Optimization Agent standalone. |
