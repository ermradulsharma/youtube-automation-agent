# Scene-Aware Retention Analysis

The Analytics Optimization Agent connects to YouTube Analytics API to fetch second-by-second retention curves.

## Insights & Feedback Loop

- **Drop-off Identification**: Flags exact timestamps where viewers left.
- **Scene Mapping**: Correlates drop-off points with script scenes and visual styles.
- **Strategy Feedback**: Feeds retention warnings back to Script Writer & Content Strategy Agents to optimize pacing in future runs.
