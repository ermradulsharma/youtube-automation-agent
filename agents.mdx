# Specialized AI Agents

YouTube Automation Agent divides channel management into 7 dedicated AI agents:

| Agent | Module | Responsibility |
| :--- | :--- | :--- |
| **Content Strategy Agent** | `agents/content-strategy-agent.js` | Researches trending topics, defines video pillars, constructs content calendars. |
| **Script Writer Agent** | `agents/script-writer-agent.js` | Drafts engaging, scene-structured scripts with visual prompts & provenance citations. |
| **Thumbnail Designer Agent** | `agents/thumbnail-designer-agent.js` | Generates high-CTR 1280x720 thumbnail concepts with bold typography overlays. |
| **SEO Optimizer Agent** | `agents/seo-optimizer-agent.js` | Generates titles, metadata, description tags, and hashtag strategies. |
| **Production Management Agent** | `agents/production-management-agent.js` | Coordinates video rendering, TTS voiceovers, scene assembly, & FFmpeg processing. |
| **Publishing Scheduling Agent** | `agents/publishing-scheduling-agent.js` | Interacts with YouTube Data API v3 for scheduled or immediate uploads. |
| **Analytics Optimization Agent** | `agents/analytics-optimization-agent.js` | Monitors retention curves, video performance, and feeds insights back into future runs. |
