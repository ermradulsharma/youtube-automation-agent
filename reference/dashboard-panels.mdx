# Web Dashboard Interface

Access the web control dashboard at `http://localhost:3456`.

## Interface Panels

1. **Overview & System Status**: Real-time server status, queue counts, and connected API health.
2. **Content Pipeline & Queue**: Visual kanban of videos moving through script, render, review, and published stages.
3. **Approval Gate Modal**: Video preview player, script text reviewer, thumbnail selector, and approve/reject controls.
4. **Shorts Repurposer Studio**: Select published long-form videos and generate vertical 9:16 Shorts.
5. **Analytics & Retention Heatmaps**: Graphs showing audience retention drop-offs and CTR trends.
